# vozduh-alert

Живая карта тревог БПЛА по публичному Telegram-каналу. Один контейнер, своя векторная подложка, обновление раз в минуту.

Прод: https://воздух-алерт.рф

**Как работает**
1. `parser_loop.py` раз в 60 секунд читает веб-версию канала t.me/vrv_radar (без API и без аккаунта), разбирает посты: строки-локации (район, область), затем событие — «опасность», «фиксация N БПЛА», «отбой». Служебные посты отсекаются эвристиками. Первый запуск бэкфилит 200 сообщений, при шквале долистывает страницы до последнего известного id, реплей идемпотентен.
2. Геокодинг через Nominatim (1 запрос/с, кэш навсегда, цепочка фоллбэков для имён вроде «X и близлежащие»), контуры районов и областей через polygon_geojson, кэшируются на волюме.
3. Состояние активных зон лежит в Redis как `active.json`, `app.py` (aiohttp) отдаёт его, nginx с микрокэшем в 1 с принимает нагрузку.
4. `index.html` — Leaflet: заливка по типу тревоги, «колода» иконок дронов по числу аппаратов, дерево областей и районов, отбои с «призраком» контура на 30 минут, бегущая строка живых событий, автофоллоу-карусель, тёмная тема.
5. Подложка — свои векторные тайлы PMTiles (вырезка из Protomaps, ~3 ГБ, z0–12, монтируется волюмом, в образ не входит) через protomaps-leaflet. Без зависимости от тайл-серверов OSM и без спорных границ.

**Состав**
- `src/` — единственный источник правды: `index.html`, `app.py`, `parser_loop.py`, `nginx.conf` (прод) и `nginx.dev.conf`, `start.sh`, `dockerfile-head`.
- `assemble.sh` собирает релизный `Dockerfile` из `dockerfile-head` и `src/` (хередоки BuildKit). Руками `Dockerfile` не править.
- `docker-compose.yml` — прод: порты 80/443, TLS в контейнере (серты волюмом, без них самоподписанный, ACME-webroot на 80-м), волюмы `data`, `regions`, `certs`, `acme`, `basemap.pmtiles`. Переменная `TME_PROXY`, если t.me из ДЦ недоступен: через прокси ходит только t.me, геокодер напрямую.
- `docker-compose.dev.yml` — дев с биндом `src/`, HTML по F5, python через restart.

**Запуск**
```bash
sh assemble.sh
docker compose up -d --build
# подложка: pmtiles extract https://build.protomaps.com/<дата>.pmtiles basemap.pmtiles --bbox=19,38,75,72 --maxzoom=12
```

**Грабли**
- User-Agent только ASCII: кириллица в заголовке роняет urllib.
- Контуры регионов обязаны жить на волюме, иначе после пересоздания контейнера вместо районов кружочки. В коде самолечение: файл пропал — перекачать.
- Порт api всегда внутренний 8080, наружу смотрит только nginx.
